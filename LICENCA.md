# Termos de uso do ÁGORA

Este documento é um rascunho de termos para o projeto ÁGORA e não substitui revisão jurídica.

## 1. Situação

Os termos de distribuição, acesso, modificação e uso comercial do ÁGORA ainda precisam ser definidos e aprovados pelo responsável pelo projeto. Até essa definição, este arquivo não concede direitos adicionais nem revoga licenças de terceiros.

## 2. Conteúdo produzido

Os direitos sobre vídeos, imagens, áudios e demais materiais exportados dependem dos materiais utilizados, das licenças aplicáveis e dos termos dos serviços externos eventualmente envolvidos.

## 3. Componentes de terceiros

Bibliotecas, fontes, modelos, efeitos sonoros, vozes e outros recursos de terceiros permanecem sujeitos às respectivas licenças e condições. Consulte `LICENCAS.md` e os avisos distribuídos junto a cada recurso.

## 4. Uso responsável

O usuário é responsável por verificar direitos autorais, direitos de imagem, autorizações, termos das plataformas e permissões necessárias para publicar ou comercializar os materiais gerados.

## 5. Revisão necessária

Antes de qualquer distribuição pública ou comercial do software, este documento deve ser revisado para identificar o titular dos direitos, o modelo de licença e as permissões concedidas.
